# Linehaul Icons

by Ewallee

![Icons](preview.png)

130 outline icons for business and logistics apps. 24 × 24, 2 px stroke, colour follows the text.
Free for any use, including commercial. ISC License.

| | |
|---|---|
| `svg/` | SVG |
| `svg-outline/` | SVG, filled outlines |
| `font/` | TTF, WOFF, WOFF2 + CSS |
| `web/` | SVG sprite, JS module, CSS |
| `png.zip` | PNG 16–128 px, 7 colours |

```html
<link rel="stylesheet" href="font/linehaul-icons.css">
<i class="lhi lhi-truck"></i>
```
